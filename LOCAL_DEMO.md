# Быстрый запуск локального backend

## Самый простой вариант
Дважды кликните `START_ALL.bat`.

Откроются два окна:
1. `ProfNav Backend` — FastAPI + SQLite.
2. `ProfNav Tunnel` — временный HTTPS-доступ через Cloudflare Tunnel.

В окне Tunnel появится адрес вида:

`https://xxxxx.trycloudflare.com`

Скопируйте его и отправьте в ChatGPT. После этого адрес будет записан в `docs/api-config.js`, и публичная GitHub Pages-версия начнёт брать живые данные с вашего компьютера.

## Поведение публичного сайта
- backend доступен → предупреждение не показывается;
- backend выключен/туннель недоступен → сверху появляется сообщение «Сервер с актуальными данными сейчас не подключен», а сайт автоматически использует сохранённый snapshot.

## Отдельный запуск
- `start_backend.bat`
- `start_tunnel.bat`

Оба окна должны оставаться открытыми во время демонстрации.
